Five words that decide everythingПять слов, которые решают всё

A minimum is a point from which no small move decreases f. A problem is convex when every chord lies above the graph, and then any local minimum is already global. It is smooth with constant L when the gradient never changes faster than L, which is exactly what makes the step 1/L safe. The condition number κ = λmax/λmin of the Hessian says how elongated the level sets are, and a large κ is the narrow valley in which plain gradient descent zigzags. At a saddle point the Hessian has eigenvalues of both signs, so the surface curves up along one direction and down along another and the gradient still vanishes. Everything else in this atlas is a strategy for coping with these five facts.Минимум — это точка, из которой никакой малый сдвиг не уменьшает f. Задача выпуклая, если любая хорда лежит не ниже графика, и тогда всякий локальный минимум уже глобальный. Она гладкая с константой L, если скорость изменения градиента нигде не превышает L, — именно это и делает шаг 1/L безопасным. Число обусловленности гессиана κ = λmax/λmin показывает, насколько вытянуты множества уровня, а большое κ — это и есть тот узкий овраг, в котором обычный градиентный спуск идёт зигзагом. В седловой точке у гессиана есть собственные значения обоих знаков: вдоль одного направления поверхность изгибается вверх, вдоль другого — вниз, а градиент всё равно обращается в нуль. Всё остальное в этом атласе — способы справиться с этими пятью фактами.
